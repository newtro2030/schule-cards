# Mathe-Grundlagen: Daten auswerten

Grundwissen Klasse 5/6 (Thüringen): Strichliste, Rangliste, Spannweite, Modalwert, Median (Zentralwert), arithmetisches Mittel, Diagramme.

## Lernkarten #Mathe/Grundlagen-Daten

Q: Was ist eine **Strichliste** und eine **Häufigkeitstabelle**?
A: **Strichliste:** Man macht für jede Nennung einen Strich. Den fünften Strich zieht man quer über die vier davor – so entstehen Fünferbündel, die man schnell zählen kann.
**Häufigkeitstabelle:** Man schreibt die **Anzahl** als Zahl dazu.

Q: Was ist eine **Rangliste**? Ordne: 7, 3, 9, 3, 5
A: Die Daten werden **der Größe nach geordnet** (vom kleinsten zum größten Wert):
**3, 3, 5, 7, 9**

Q: Was ist die **Spannweite**? Bestimme sie für 3, 3, 5, 7, 9.
A: **Größter Wert minus kleinster Wert.**
9 − 3 = **6**

Q: Was ist der **Modalwert**? Bestimme ihn für 3, 3, 5, 7, 9.
A: Der Wert, der **am häufigsten** vorkommt: **3**

Q: Was ist der **Median** (Zentralwert)? Bestimme ihn für 3, 3, 5, 7, 9.
A: Der Wert **in der Mitte** der Rangliste: 3, 3, **5**, 7, 9 → Median = **5**
Bei einer **geraden** Anzahl: der Mittelwert der beiden mittleren Zahlen.
2, 4, **6, 8**, 10, 12 → (6 + 8) : 2 = **7**

Q: Was ist das **arithmetische Mittel** (Durchschnitt)? Bestimme es für 3, 3, 5, 7, 9.
A: **Alle Werte addieren** und durch die **Anzahl** teilen:
(3 + 3 + 5 + 7 + 9) : 5 = 27 : 5 = **5,4**

Q: Eine Schülerin hat in Mathe die Noten 2, 1, 3, 2 geschrieben. Wie ist ihr Durchschnitt?
- [ ] 2,5
- [x] 2
- [ ] 8
- [ ] 1,5
A: (2 + 1 + 3 + 2) : 4 = 8 : 4 = **2**

Q: Ordne zu: Daten 1, 2, 2, 4, 6 – was ist richtig?
- [x] Modalwert = 2
- [x] Median = 2
- [x] Spannweite = 5
- [ ] arithmetisches Mittel = 2
A: Mittel: (1 + 2 + 2 + 4 + 6) : 5 = 15 : 5 = **3**

Q: Welche **Diagramme** gibt es, und wofür eignen sie sich?
A: **Säulendiagramm** (senkrechte Säulen) und **Balkendiagramm** (waagerechte Balken): zum **Vergleichen** von Anzahlen
**Kreisdiagramm:** zeigt **Anteile an einem Ganzen** (z. B. wie sich eine Klasse auf Lieblingsfächer verteilt)
**Liniendiagramm:** zeigt eine **Entwicklung über die Zeit** (z. B. Temperatur am Tag)
